# 小说伴读阅读器原型

这是 AI Reading Companion 仓库中的浏览器阅读器 UI 原型。它用于体验导入小说、阅读设置、目录检索、书签、笔记和浮动伴读助手交互。

## 打开方式

1. 下载或克隆整个仓库。
2. 打开本目录中的 `index.html`；也可以在本目录启动一个静态文件服务器后访问页面。
3. 点击页面上的“导入我的 TXT”，导入一本含章节标题的整本 TXT，或按文件名数字排序的多个分章 TXT。

使用 Python 启动静态页面服务器（可选）：

```powershell
cd novel-companion-redesign
py -m http.server 5173
```

浏览器访问 <http://127.0.0.1:5173>。关闭服务器时，在终端按 `Ctrl+C`。

## 阅读器功能

- 导入单个整书 TXT，按“第 X 章 / 回”等独立标题行拆分章节；也可多选分章 TXT。
- 搜索并跳转目录章节，使用字号、行距和背景设置。
- 保存阅读进度、书签和阅读笔记到当前浏览器的本地存储。
- 选中正文后，可呼出小阅提问；右键小阅可打开功能菜单。

导入的 TXT 由浏览器本地读取。当前原型没有把导入文件上传到项目服务器。

## 伴读模型连接说明

伴读聊天请求本地流式代理地址：`http://localhost:8787/api/companion/stream`，模型默认配置在 `pet-menu.js` 中，使用 Ollama OpenAI 兼容服务（默认 `http://localhost:11434/v1`、`qwen2.5:7b`）。要使用真实模型，需要本机启动 Ollama、下载相应模型，并启动一个实现上述代理路由的服务。

**注意：该流式代理服务没有包含在本仓库中。** 因此仅打开本页面时，阅读器界面可以使用，但 AI 提问会因代理不可用而失败。本仓库里的 FastAPI 后端运行在 `http://127.0.0.1:8000`，目前还没有与此原型连接。后端启动步骤和 API 示例请看仓库根目录的 README。

## 已知限制

- TXT 自动分章依赖独立一行的章节标题；格式特殊的文本可能需要先整理标题格式。
- 阅读进度、书签、笔记和章节总结缓存保存在浏览器本地；清除站点数据会删除这些内容。
- 小阅的 AI 问答、章节总结和章节检索依赖未随仓库提供的本地代理服务。
